# AM4 Hub Planner

Unofficial fan tool for **Airline Manager 4**: calculates which routes from your hub earn the most, and with which aircraft, for the capital you have (one aircraft, several aircraft on separate routes, or several aircraft per route).

Live: <https://globalairall.net/tools/am4hub.html> · Description: <https://globalairall.net/tools/am4hub_description.html>

## Structure

| Part | Where | Repository |
| --- | --- | --- |
| Logic and tool styles | `site/tools/hubplanner/am4hub.js`, `am4hub.css` → `www/tools/hubplanner/` | this one |
| Pages (`am4hub.html`, `am4hub_description.html`) | `www/tools/` | [website](https://github.com/Global-Air-Alliance/website) (Bootstrap Studio) |
| Aircraft list, game data, shared styles | `www/tools/shared_resources/` | [AM4-Tools_Shared_Resources](https://github.com/Global-Air-Alliance/AM4-Tools_Shared_Resources) |

The page loads `shared_resources/am4.js` first, then `hubplanner/am4hub.js`.

## Language

The tool is written in English only and translated on the website by Linguise.
Texts generated by the script are read from the hidden block `<div id="am4-strings">` of the page (`AM4.strings()`), so Linguise translates them together with the page. Containers filled by the script and the country/airport selects carry the class `no-translate`. Numbers are formatted in the visitor's browser locale.

## Deployment

Every push to `main` that changes `site/` runs the workflow **Deploy Hub Planner** (`.github/workflows/deploy.yml`): rsync over SSH to `www/tools/hubplanner/`, then a message per commit in the Discord forum post of the tool; on failure an e-mail. Variables and secrets are listed at the top of the workflow file.
